# actor-inochi — living-world organ

`actor-inochi` is the governed living-world organ of the Tamaki-centered
Etzhayyim artificial organism. It mirrors species, ecosystems, biomes, and
ecological pressures into append-only Kotoba data and routes aggregate findings
toward restoration. It never produces precise target lists or assigns value to
living beings.

The actor proposes bounded observations under the gates in `manifest.edn`.
Tamaki retains organism-level authority. The former repository name
`com-etzhayyim-inochi` remains a compatibility redirect.
